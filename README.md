# Наш класс

Четыре рисованных «мира» для школьного класса: 🌳 Сад добрых дел · 📚 Книжная полка · 🚂 Поезд класса · 💌 Ящик тревог (анонимный).
Много классов: учитель создаёт класс на главной, ученики регистрируются по ссылке и паролю класса.

React + Vite на GitHub Pages, база и аккаунты — Supabase (бесплатный тариф).
Без ключей сайт работает в **демо-режиме** (данные в браузере, готовый класс 6А).

## Как это работает
- **Учитель** на главной: «Создать класс» (школа, класс, логин, пароль, пароль класса) → получает ссылку вида `…/#/c/abc123`.
- **Ученик** открывает ссылку → вводит пароль класса → выбирает своё имя из списка (или вводит новое), придумывает логин и пароль. Дальше заходит на главной с логином и паролем.
- Данные классов изолированы правилами базы (RLS): ученик видит только свой класс.
- **Ящик тревог:** таблица `worries` читается только автором. Учитель видит письма через `teacher_inbox()` без автора, в «перемешанном» порядке и с датой без времени. Ответ видит только автор.
  Оговорка: владелец проекта Supabase технически может открыть базу целиком, поэтому не давайте доступ к панели Supabase никому, кроме себя.

## Запуск у себя
```bash
npm install
npm run dev
```

## Подключение сервера (один раз, ~10 минут)
1. supabase.com → New project (бесплатно).
2. **SQL Editor** → вставьте весь `supabase/schema.sql` → Run.
3. **Authentication → Providers → Email**: выключите «Confirm email». Там же (Sign In / Providers) оставьте регистрацию включённой.
4. **Project Settings → API**: скопируйте `Project URL` и `anon public` key → в `.env.local` (по образцу `.env.example`) и в `./scripts/deploy.sh` они подхватятся сами.
5. Предзаполненный класс 6А «с 1 сентября»: `node scripts/make-seed-sql.mjs` создаёт `supabase/seed_6a.sql`.
   Вставьте его в SQL Editor, впишите в начале логин учителя, пароль учителя и пароль класса, нажмите Run (секретные ключи не нужны, можно запускать повторно).
   Список учеников — в `scripts/roster.txt` (по одному на строку, в git не попадает); без него возьмутся вымышленные имена.

## Публикация на GitHub Pages
Сайт лежит в ветке `gh-pages`. Обновить после изменений: `./scripts/deploy.sh` (ключи Supabase берутся из `.env.local`).
Готовый workflow для авто-публикации — `docs/deploy.yml.example`.

## Ограничения
Подбор пароля класса ограничен (10 неудачных попыток за 10 минут на класс). Пароль учителя — стандартная защита Supabase Auth.
